# Anas Developer

هذا هو الموقع التعريفي الشخصي لـ **أنس القيسي**.
يعرض الموقع الخدمات التي أقدمها، نماذج من الأعمال السابقة، وطريقة التواصل لطلب مشروع جديد.

الموقع مكتوب بـ HTML وCSS وJavaScript فقط، لذلك لا يحتاج إلى React أو Node.js أو أي عملية build.

## تشغيل الموقع على جهازك

بعد تنزيل المشروع، افتح PowerShell داخل مجلد المشروع وشغّل أحد الأوامر التالية:

```bash
npx serve .
```

أو إذا كان Python مثبتاً لديك:

```bash
python -m http.server 4173
```

بعدها افتح الرابط الذي يظهر لك في المتصفح، وغالباً سيكون:

```text
http://localhost:4173
```

يمكن فتح `index.html` مباشرة، لكن تشغيل خادم محلي أفضل حتى تعمل الصور والملفات الخارجية بشكل صحيح.

## ماذا يحتوي الموقع؟

- صفحة رئيسية باللغة العربية واتجاه RTL.
- تصميم متجاوب مع الجوال والكمبيوتر.
- تبديل بين الوضع الداكن والوضع الفاتح.
- معرض صور تفاعلي لمشروع سجلي.
- نموذج للتواصل وإرسال طلبات المشاريع.
- عرض وثيقة العمل الحر وشهادة المركز السعودي للأعمال.

## أين أعدل المحتوى؟

| الملف | الاستخدام |
| --- | --- |
| `index.html` | النصوص، الأقسام، روابط التواصل، ومحتوى المشاريع |
| `style.css` | الألوان، المسافات، الخطوط، والتصميم المتجاوب |
| `app.js` | القائمة، الوضع الليلي، معرض الصور، النموذج، والنوافذ المنبثقة |
| `assets/brand/` | شعار الموقع |
| `assets/certificates/` | الشهادات وملفاتها |
| `assets/projects/` | صور وملفات المشاريع |

## إضافة مشروع جديد

أنشئ مجلداً باسم المشروع داخل:

```text
assets/projects/
```

مثال:

```text
assets/projects/my-project/
├── main.png
├── screenshot-01.png
└── screenshot-02.png
```

بعد ذلك أضف المشروع في قسم الأعمال داخل `index.html`، واستخدم المسارات التي تبدأ بـ:

```text
assets/projects/my-project/
```

بهذه الطريقة تبقى ملفات كل مشروع معاً ولا تختلط مع صور المشاريع الأخرى.

## نموذج التواصل

نموذج التواصل يستخدم خدمة FormSubmit لإرسال الرسائل. إذا تعذر الإرسال، يحاول الموقع فتح تطبيق البريد الإلكتروني مباشرة.

إذا أردت تغيير البريد المستخدم في المسار الاحتياطي، عدّل قيمة `CONTACT_EMAIL` في بداية ملف `app.js`.

## النشر

يمكن نشر المشروع مباشرة على:

- GitHub Pages
- Netlify
- Vercel
- أي استضافة تدعم المواقع الثابتة

لا توجد خطوة build. ارفع محتويات المستودع كما هي، واجعل مجلد المشروع هو مجلد النشر.

## الترخيص

المحتوى والصور والشعارات الموجودة في هذا المستودع مملوكة لصاحب المشروع. لا تستخدمها أو تعيد نشرها دون إذن.
