# Anas Developer — Personal Portfolio

موقع أنس القيسي الشخصي لعرض الخدمات، نماذج الأعمال، وطرق التواصل لطلب مشروع جديد.

المشروع مبني باستخدام **HTML وCSS وJavaScript** فقط. لا يوجد إطار عمل أو خطوة بناء، لذلك
يبقى الموقع خفيفاً وسهل النشر على أي استضافة ملفات ثابتة.

## المميزات

- واجهة عربية باتجاه RTL ومتجاوبة مع الجوال والكمبيوتر.
- وضع داكن ووضع فاتح مع حفظ تفضيل المستخدم.
- معرض صور تفاعلي لمشروع سجلي.
- نموذج تواصل عبر FormSubmit مع مسار احتياطي لتطبيق البريد الإلكتروني.
- نوافذ لعرض وثيقة العمل الحر وشهادة المركز السعودي للأعمال.
- تأثيرات حركة خفيفة مع دعم `prefers-reduced-motion`.

## المعاينة

يمكن تشغيل الموقع محلياً باتباع التعليمات أدناه. رابط GitHub Pages غير مفعّل حالياً، لذلك
لم تتم إضافة رابط معاينة عام غير مؤكد إلى هذا الملف.

## التشغيل محلياً

بعد تنزيل المستودع، افتح PowerShell داخل مجلد المشروع وشغّل أحد الأمرين:

```bash
npx serve .
```

أو:

```bash
python -m http.server 4173
```

ثم افتح:

```text
http://localhost:4173
```

يمكن فتح `index.html` مباشرة، لكن الخادم المحلي هو الخيار الأفضل لضمان تحميل الصور والملفات
الخارجية كما هو متوقع.

## نموذج التواصل

يرسل النموذج البيانات إلى خدمة FormSubmit. إذا فشل الطلب أو لم يتوفر الاتصال بالخدمة،
يحاول الموقع فتح تطبيق البريد الإلكتروني باستخدام العنوان الموجود في `app.js`.

> لا تضع مفاتيح سرية أو بيانات اعتماد داخل ملفات الواجهة الأمامية.

## النشر

هذا المشروع مناسب للنشر مباشرة على:

- GitHub Pages
- Netlify
- Vercel
- أي استضافة للمواقع الثابتة

لا توجد خطوة `build`. استخدم جذر المستودع كمجلد النشر.
