# مرصد وبوابة المبرمج — Anas Developer Command Center

منظومة برمجية متكاملة مخصصة لإدارة وتتبع المشاريع البرمجية، التحقق من أفكار المنتجات، تسجيل تواصل العملاء والمستخدمين، وإدارة العقود والدفعات مع بوابة تفاعلية مخصصة للعملاء.

---

## 🌟 الميزات الرئيسية

1. **مرصد الأفكار والتحقق من السوق (Ideas Lab & Validation Hub):**
   - تسجيل الأفكار ومشاكل السوق المستهدفة قبل البدء في البرمجة.
   - متابعة مراحل المقابلات وردود الأفعال ومستوى الجاهزية للدفع.
   - توثيق الاحتياجات التقنية ونماذج الربح والتسعير.

2. **سجل تواصل العملاء والمستخدمين (Outreach & CRM):**
   - تسجيل ومتابعة المهتمين عبر القنوات المختلفة (واتساب، X، تيك توك، مكالمات، قنوات أخرى).
   - توثيق الملاحظات وسير الحوارات والمواعيد اللاحقة للمتابعة.

3. **إدارة مشاريع العملاء والعقود (Client Projects & Contracts):**
   - متابعة تقدم المشاريع ومراحل التسليم (Milestones) والدفعات المستحقة والمحصلة.
   - توليد عقود قانونية رسمية ثنائية اللغة متوافقة مع الأنظمة السعودية قابلة للطباعة والتصدير.
   - روابط وصول خاصة للعميل محكمة برمز PIN مخصص دون الحاجة لكلمة مرور.

4. **بوابة العميل التفاعلية (Client Portal View):**
   - صفحة نظيفة مخصصة للعميل لمراجعة تقدم مشروعه، الدفعات، وروابط النسخ التجريبية.

5. **ناشر معرض الأعمال (Portfolio Showcase Manager):**
   - إدارة ونشر مشاريع البورتفوليو العام مع مزامنة فورية سحابية (Firebase) ومحلية (`projects.json` و `categories.json`).

---

## 🛠️ التقنيات المستخدمة

- **الواجهة:** React 19 + TypeScript + Tailwind CSS
- **أداة البناء:** Vite 8
- **الأيقونات:** Lucide React
- **قاعدة البيانات والمصادقة:** Google Cloud Firebase (Auth + Firestore)
- **الخادم المحلي المصغر:** Vite Custom Dev Middlewares لإدارة وحفظ أصول المعرض محلياً

---

## 🚀 التشغيل المحلي

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل السيرفر المحلي (منفذ 3000)
npm run dev

# 3. فحص الأنواع (Type-check)
npm run lint

# 4. تشغيل الاختبارات
npm test

# 5. بناء نسخة الإنتاج
npm run build
```

## 🔒 الأمان والمصادقة
 
- تسجيل الدخول الإداري محمي بواسطة Firebase Authentication ومحصور حصرياً بالبريد المعتمد للمدير مع قواعد أمان صارمة في Cloud Firestore.
- دخول بوابة العميل معزول برمز وصول عشوائي قوي (PIN) مُولّد بمولد أرقام عشوائية مشفر (CSPRNG)، وتمنع قواعد Firestore استعراض قائمة المشاريع (List Denied) وتسمح فقط بقراءة المستند الخاص بالرمز الصحيح.
- جميع مسارات خدمة الملفات والأصول في خادم التطوير مزودة بحماية من Path Traversal وحدود قصوى للأحجام المرفوعة وتدقيق الامتدادات المسموحة.
